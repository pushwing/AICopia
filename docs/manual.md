# AICopia 사용 매뉴얼

AICopia는 CodeIgniter 4 기반의 AI 운영 보조형 쇼핑몰 솔루션입니다. 이 매뉴얼은 **고객(쇼핑몰 이용자)**과 **관리자(운영자)** 두 대상을 모두 다룹니다.

- **1부 — 고객 이용 가이드**: 회원가입부터 구매·마이페이지까지 실제 쇼핑 흐름
- **2부 — 관리자 운영 매뉴얼**: 상품·주문·회원·마케팅·AI·시스템 운영
- **3부 — 운영자 참고**: 주문 상태 흐름, 배치 작업, 권한/보안 요약

> 이 매뉴얼은 저장소의 실제 구현 화면(컨트롤러·뷰·라우트)을 조사해 작성했습니다. 화면 명칭은 실제 코드 기준이며, 표시 문구는 테마/설정에 따라 달라질 수 있습니다.

# 1부. 고객 이용 가이드

## 1.1 회원가입과 로그인

### 회원가입
1. 상단 메뉴에서 **회원가입**(`/auth/register`)으로 이동합니다.
2. 다음 정보를 입력합니다.
   - **필수**: 이메일, 비밀번호, 닉네임, 전화번호
   - **선택**: 주소, 성별, 생년월일
3. 가입을 완료하면 입력한 이메일로 **인증 메일**이 발송되고, **이메일 인증 대기** 화면(`/auth/verify-pending`)으로 이동합니다.
4. 메일의 인증 링크를 클릭하면 인증이 완료되고 **가입 축하 포인트**가 지급됩니다.

> **중요**: 이메일 인증을 완료하기 전에는 로그인할 수 없습니다. 메일이 오지 않으면 인증 대기 화면에서 **재발송**을 누르세요(1분 쿨다운 적용).

### 로그인 / 로그아웃
- **로그인**: `/auth/login`에서 이메일·비밀번호를 입력합니다.
- 비로그인 상태에서 담아둔 장바구니는 로그인 시 **자동으로 회원 장바구니에 병합**됩니다.
- **로그아웃**: `/auth/logout` (세션 종료 후 홈으로 이동)

---

## 1.2 소셜 로그인

- 로그인/회원가입 화면에서 소셜 로그인 버튼(구글 · 네이버 · 카카오)을 사용할 수 있습니다. *(관리자 설정에서 활성화된 제공자만 노출)*
- 소셜 계정으로 처음 로그인하면 **자동 회원가입**되며, 가입 축하 포인트가 지급됩니다.
- 소셜 계정의 이메일이 기존 회원과 같으면 **기존 계정에 자동 연동**됩니다.
- 닉네임이 중복되면 숫자 접미사가 자동으로 붙습니다.

---

## 1.3 내 정보 관리

- **내 정보 보기/수정**: `/auth/profile`
  - **기본정보 탭**: 닉네임, 전화번호, 성별, 생년월일 수정
  - **비밀번호 탭**: 비밀번호 변경
  - **회원 탈퇴 탭**: 탈퇴 사유를 선택하고 확인 절차를 거쳐 탈퇴를 신청합니다.
    - **탈퇴 불가 상황**: 진행 중인 주문(pending/awaiting_payment/preparing), 진행 중인 반품/교환 건이 있거나, 관리자 계정인 경우 탈퇴할 수 없습니다.
    - **탈퇴 후**: 회원 정보(이메일, 개인정보)는 즉시 마스킹되며, 주문/배송 조회만 가능합니다.
    - **개인정보 파기**: 탈퇴 후 일정 기간(`/admin/settings`의 `withdrawal_retention_days` 설정, 기본 30일)이 지나면 개인정보가 자동 파기됩니다.
  - 소셜 계정으로 가입한 경우 해당 연동 여부가 표시됩니다.

## 1.4 상품 탐색과 검색

- **홈**(`/`): 신상품, 할인상품, 진행 중 기획전, 배너, 공지사항이 노출됩니다.
- **상품 목록**(`/shop`): 다음 조건으로 필터·정렬할 수 있습니다.
  - 키워드 검색 (AI **시맨틱 검색**으로 유사어까지 확장 검색)
  - 카테고리 선택
  - 가격 범위
  - 정렬 (신상품/가격 등)
  - **할인 상품만 보기**
- 로그인 사용자는 목록 상단/찜 목록 하단 등에서 **개인화 추천 상품**을 볼 수 있습니다.

## 1.5 상품 상세 · 리뷰 · Q&A · 재입고 알림

**상품 상세**(`/shop/{상품슬러그}`)에서 할 수 있는 것:

| 기능 | 설명 | 로그인 |
|------|------|:---:|
| 옵션/SKU 선택 후 장바구니 담기 | 옵션 조합별 재고 확인 | 불필요 |
| **찜하기** | 관심 상품 저장(토글) | 필요 |
| **리뷰 작성** | 별점(1~5) + 내용 + 이미지 최대 3장 | 필요 |
| **상품 Q&A 작성** | 제목·내용, 비밀글 설정 가능 | 필요 |
| **재입고 알림 신청** | 품절 시 재입고되면 알림 | 이메일 입력 시 비회원도 가능 |

> **리뷰 포인트 혜택**: 30자 이상 작성 + 이미지 1장 이상 첨부 시 **150 포인트**가 지급됩니다.

- 최근 본 상품은 자동으로 저장되어(최대 10개) 상세 하단에 표시됩니다.
- 본인이 작성한 리뷰·Q&A는 본인만 삭제할 수 있습니다.

## 1.6 장바구니

- **담기**(`/cart/add`): 비로그인 상태에서도 담을 수 있습니다(세션 저장). 로그인하면 DB로 옮겨져 유지됩니다.
- **장바구니 보기**(`/cart`): 로그인 필요
- **수량 변경 / 삭제 / 비우기**: 로그인 필요. 수량은 재고 상한을 넘지 않도록 자동 조정됩니다.

## 1.7 주문과 결제

### 주문서 작성 (`/order`)
1. 장바구니에서 주문서로 이동합니다.
2. **배송지 선택**: 저장된 배송지를 고르거나 새로 입력합니다.
3. **쿠폰 적용**: 쿠폰 코드를 입력하면 실시간으로 유효성과 할인 금액이 검증됩니다.
4. **포인트 사용**: 보유 포인트를 결제에 사용할 수 있습니다.
5. **결제 수단 선택**: 아래 지원 수단 중 선택합니다.

### 지원 결제 수단
| 수단 | 설명 |
|------|------|
| 무통장입금 | 주문 후 안내된 계좌로 입금 |
| 토스페이먼츠 / KG이니시스 / 나이스페이 | 신용카드 등 일반 PG |
| 카카오페이 / 네이버페이 / 페이코 | 간편결제 |

*(실제 노출되는 수단은 관리자 설정에 따릅니다.)*

### 결제 진행
- 배송비는 금액/무게/지역 기준으로 **자동 계산**됩니다. 최소 결제 금액 제한이 있을 수 있습니다.
- **카드·간편결제**: PG 화면에서 결제 → 성공 시 **결제 완료**(`/order/complete/{주문번호}`)로 이동합니다.
- **무통장입금**: **입금 안내**(`/order/bank_transfer/{주문번호}`) 화면에서 계좌·입금자명을 확인하고 입금합니다.
- 결제 실패 시 **결제 실패**(`/order/fail/{주문번호}`) 화면에서 사유를 확인할 수 있습니다.

> **재고 안내**: 재고는 **결제가 실제로 확인된 시점**에 차감됩니다. 장바구니에 담는 것만으로는 재고가 줄지 않습니다. 결제 전 주문(pending)은 30분 내 미결제 시 자동 만료됩니다.

## 1.8 마이페이지

**주문 내역** (`/mypage/orders`)
- 기간(1개월/3개월/전체)·상태·키워드로 조회합니다.
- **주문 상세**(`/mypage/orders/{주문번호}`)에서:
  - **배송 완료 확인**: 배송중(shipped) → 배송완료(delivered) 처리
  - **즉시 취소**: 결제 전(pending)·입금 대기(awaiting_payment) 상태에서만 가능
  - **재주문**: 기존 주문 상품을 장바구니에 다시 담기
  - **반품 신청** / **교환 신청**: 배송 완료 후 **7일 이내**에 사유를 선택해 신청 → 관리자 승인 대기

**배송지 관리** (`/mypage/addresses`)
- 배송지 추가, 기본 배송지 설정, 삭제. 기본 배송지를 삭제하면 다음 주소가 자동으로 기본값이 됩니다.

**쿠폰**(`/mypage/coupons`) · **포인트**(`/mypage/points`) · **찜 목록**(`/mypage/wishlist`)
- 쿠폰: **사용 가능 / 사용됨** 탭으로 구분
- 포인트: 적립·사용 내역과 잔액
- 찜 목록: 찜한 상품과 하단 개인화 추천

## 1.9 쿠폰 · 포인트 · 회원 등급

**쿠폰 종류**
| 종류 | 설명 |
|------|------|
| 정액 할인(fixed) | 지정 금액 할인 |
| 정률 할인(percent) | 지정 비율 할인 |
| 무료배송(free_shipping) | 배송비 면제 |

- 쿠폰은 관리자 발급 또는 **생일 쿠폰** 등 자동 발급으로 지급됩니다.
- 주문서에서 코드 입력 시 실시간 검증(`/coupon/check`)됩니다.

**포인트**: 가입·리뷰·구매 등으로 적립되며 결제 시 사용할 수 있습니다. 내역은 마이페이지에서 확인합니다.

**회원 등급**: 구매 실적 등에 따라 등급(예: bronze/silver/gold/platinum)이 산정되며, 등급 전용 기획전 접근 등 혜택이 있습니다.

## 1.10 기획전 · 게시판 · 문의

**기획전** (`/promotions`, `/promotion/{슬러그}`)
- 세일·이벤트 모음. 일부 기획전은 **회원 등급 제한**이 있어 조건 미충족 시 안내 화면이 표시됩니다.

**게시판** (`/board/{게시판슬러그}`)
- 공지사항 상단 고정, 제목/내용/작성자 검색, 페이지네이션
- **글쓰기**: 회원은 자동 표시, 비회원은 비밀번호 설정 필요
- 첨부파일, 에디터 이미지 업로드, 비밀글, 댓글(회원) 지원
- 비회원 글은 수정·삭제 시 **비밀번호 확인**을 거칩니다.

**문의하기** (`/inquiry/submit`, 보통 Contact 페이지에서 제출)
- 이름·이메일·전화·제목·메시지를 접수하면, **AI가 자동으로 문의를 분류**하고 관리자에게 메일로 전달합니다.

# 2부. 관리자 운영 매뉴얼

> 모든 관리자 화면은 `/admin` 하위 경로이며 **관리자 로그인**이 필요합니다. 기본 관리자 계정은 초기 시드로 생성됩니다(`admin@example.com`).

## 2.1 관리자 로그인과 대시보드

- **대시보드** (`/admin`, `/admin/dashboard`)
  - 핵심 지표 요약, **최근 30일 매출 그래프**, **상품별 판매량 TOP 5**
  - 상단에 미확인 문의 등 알림 배지가 표시됩니다.

---

## 2.2 상품 관리

**경로**: `/admin/products`

| 작업 | 설명 |
|------|------|
| 상품 등록/수정/삭제 | 가격·할인가·재고·상태·배송정보·공급사·추천여부 |
| **상품 복제** | 기존 상품을 복제해 빠르게 등록 |
| **일괄 작업** | 여러 상품 동시 처리 |
| **재고 수정** | 목록에서 바로 재고 조정 |
| **추천상품 토글** | 메인 노출용 추천 지정 |
| 이미지 관리 | 다중 이미지, 대표 이미지, **배경 제거** |
| **엑셀 임포트/내보내기** | 템플릿 다운로드 → 대량 등록/수정 |
| **카테고리 관리** | 계층형 카테고리 CRUD (별도 화면) |
| **미분류 상품 관리** | 카테고리 미지정 상품 정리 |
| 네이버 상품 검색/임포트 | 외부 상품 정보·이미지 가져오기 |

**AI 보조 기능**
- **상품 설명 자동 생성**: 상품명/속성으로 상세 설명 초안 작성
- **이미지에서 정보 추출**: 상품 이미지로 속성 자동 추출
- **카테고리 추천**: 상품에 맞는 카테고리 제안

## 2.4 주문 관리

**경로**: `/admin/orders`

**목록/상세**
- 상태·기간·키워드로 조회, 엑셀 다운로드, **일괄 상태 변경**
- **주문 상세**(`/admin/orders/detail`)에서 배송 정보, 결제 정보, 반품/교환 처리, **주문 메모**(관리자 내부 노트) 관리

**결제/배송 처리**
| 작업 | 설명 |
|------|------|
| **무통장입금 확인** | 입금 확인 시 결제완료 처리 + 재고 차감 |
| 배송번호 입력 | 개별 입력 또는 **배송추적 일괄 업로드**(`/admin/orders/tracking_upload`, 템플릿 제공) |
| 상태 변경 | 결제완료 → 배송준비 → 배송중 → 배송완료 |
| **취소 / 환불** | 재고 복원 처리 |
| **반품 승인/거부** | 배송완료 후 신청 건 처리 |
| **교환 승인/거부/완료** | 교환 라인 아이템 관리 |

**이상 주문 탐지** (`/admin/orders/anomalies`)
- AI 기반으로 **사기 의심 주문**을 탐지해 목록으로 제공합니다.

> **동시성 안전장치**: 재고 차감은 트랜잭션 안에서 행 잠금(`FOR UPDATE`) + 조건부 업데이트로 처리되고, 중복 PG 콜백은 `pg_tid` UNIQUE 제약으로 무시됩니다.

## 2.13 AI 운영 기능 총정리

AICopia의 AI 보조 기능은 화면 곳곳에 분산되어 있습니다. 한눈에 정리하면:

| 기능 | 위치 | 처리 방식 |
|------|------|------|
| 카테고리 추천 | 상품 등록 | 실시간 |
| 상품 설명 생성 | 상품 등록 | 실시간 |
| 이미지 정보 추출 | 상품 등록 | 실시간 |
| 재입고 제안 | 재고 관리 | 실시간/배치 |
| 매출 분석 리포트 | 매출 관리 | 실시간 |
| 이상 주문 탐지 | 주문 관리 | 실시간 |
| 리뷰 요약 | 리뷰(고객 상세) | **비동기 잡** (`review_summary`) |
| 문의 자동 분류 | 문의 수신함 | **비동기 잡** (`inquiry_classify`) |
| Q&A/문의 답변 제안 | Q&A·문의 | 실시간 |
| 시맨틱 검색 | 고객 상품 검색 | 실시간 |

- **제공자 선택**: 설정의 `ai_provider`(groq / claude / openrouter). API 키는 설정값 우선, 없으면 `.env`.
- 오래 걸리는 작업은 `ai_jobs` 큐에 쌓이고 `php spark ai:work`(스케줄의 AI 작업 처리)로 처리됩니다.

# 3부. 운영자 참고

## 3.1 주문 상태 흐름도

```
pending ──[PG 결제]──▶ paid ─▶ preparing ─▶ shipped ─▶ delivered
   │
   ├──[무통장입금]──▶ awaiting_payment ──[관리자 확인]──▶ paid
   │
   └──(30분 내 미결제)──▶ expired               (재고 미점유)

paid/preparing ──[취소]──▶ cancelled            (재고 복원)
refund_requested ─▶ refunded

delivered ──[회원, 7일 이내 반품]──▶ return_requested
      ├─[승인]─▶ return_approved ─▶ refunded
      └─[거부]─▶ delivered

delivered ──[교환]──▶ exchange_requested
      └─[승인]─▶ exchange_approved ─▶ exchange_completed
```

- `delivered_at`은 배송완료 전환 시 기록되며, 반품/교환 가능 기간(7일)의 기준입니다.
- 상태 전이는 단방향으로 강제되며, 모든 변경은 `order_status_logs`에 감사 기록됩니다.

## 3.2 배치/크론 작업

운영 크론(1줄):
```
* * * * * cd /path/to/AICopia && php spark tasks:run >> /dev/null 2>&1
```
개별 실행 예:
```
php spark orders:expire 30      # 30분 초과 미결제 주문 만료
php spark grades:upgrade        # 등급 재계산
php spark coupons:birthday      # 생일 쿠폰 발급
php spark stats:purge-logs      # 접속 로그 정리
php spark ai:work               # AI 잡 처리
```

## 3.3 권한 · 보안 요약

- **관리자 영역**: 모든 `/admin/*`는 `auth:admin` 필터로 보호됩니다.
- **회원 전용**: 장바구니 조회/수정/삭제, 주문/결제, 마이페이지, 찜/리뷰/Q&A 작성은 `auth:member` 필요.
- **비회원 허용**: 상품 탐색, 장바구니 담기(`cart/add`, 세션 저장), 게시판 열람/비밀번호 기반 글쓰기, 재입고 알림 신청.
- **CSRF**: 모든 폼에 토큰이 적용되며, PG 콜백(`payment/callback/*`) 등 외부 유입 경로만 예외입니다.
- **재고/결제 무결성**: 결제 확인 시점에만 재고 차감, 중복 PG 콜백은 `pg_tid` UNIQUE로 차단.
