# 장바구니 본품 해제 시 애드온 자동 해제·잠금 — 설계

## 배경

`app/Views/shop/cart.php`는 `AddonGrouping::order()`가 매긴 `is_addon` 플래그로 애드온 항목을 본품 바로 아래에 시각적으로만(들여쓰기 + "추가구성" 배지) 구분한다. 체크박스(`.item-check`)는 본품·애드온 구분 없이 완전히 독립적으로 동작해서, 본품 체크를 해제해도 애드온은 그대로 선택된 채 결제까지 진행될 수 있다. 애드온은 본품에 종속된 부속 상품 개념이므로 이 동작은 사용자 혼란(본품 없이 부속만 결제)을 유발한다.

## 목표

장바구니 화면에서 **본품 체크박스를 해제하면 그 본품에 연결된 애드온 체크박스도 자동으로 해제되고, 본품이 미선택 상태인 동안은 애드온 체크박스를 잠가(disabled) 독립 선택을 막는다.** 본품을 다시 체크하면 애드온 체크박스는 다시 활성화되고, 잠기기 직전에 사용자가 선택했던 상태로 복원된다(최초 로드 시 기본값은 선택됨).

이번 작업 범위는 **클라이언트(뷰/JS) UX 한정**이다. 애드온 단독 결제를 서버(`CartController::checkout()` 등)에서 막는 검증은 이번 범위에서 제외한다(필요 시 별도 작업으로 진행).

## 변경 범위

파일 1개, `app/Views/shop/cart.php`만 수정. 서버(컨트롤러/모델/DB) 변경 없음 — `parent_product_id`는 이미 `CartModel::getByUser()`가 select해 `AddonGrouping::order()`를 거친 `$items` 배열에 들어있으므로 쿼리 변경도 불필요하다.

1. **데이터 속성 추가**: 애드온 카드(`$isAddon === true`)에 `data-parent-product-id="<?= (int) $item['parent_product_id'] ?>"`를 추가한다. 본품을 찾지 못한 "고아 애드온"은 `AddonGrouping`이 이미 `is_addon = false`로 처리하므로 이 속성이 붙지 않고, 자연히 이번 로직의 적용 대상에서 제외된다.

2. **인라인 스크립트에 잠금 로직 추가**:
   - 본품(`item-check`)의 `change` 이벤트 핸들러에서, 같은 `data-product-id`를 `data-parent-product-id`로 갖는 애드온 카드들을 찾아 처리한다.
     - 본품이 **미체크**되면: 각 애드온 체크박스의 현재 `checked` 값을 `dataset.prevChecked`에 저장한 뒤 `checked = false`, `disabled = true`로 만든다.
     - 본품이 **체크**되면: 각 애드온 체크박스를 `disabled = false`로 풀고, `dataset.prevChecked`에 저장된 값이 있으면 그 값으로 `checked`를 복원한다(없으면 — 즉 최초 로드 시 기본 선택 상태 — 그대로 둔다).
     - 두 경우 모두 마지막에 `updateSummary()`를 호출해 요약/결제 버튼 상태를 갱신한다.
   - **페이지 로드 시 1회 초기화**: 기존 `updateSummary()` 호출 지점 근처에서 위 로직을 모든 본품 카드에 대해 한 번 실행한다. 본품이 품절 등으로 처음부터 미체크(`disabled`) 상태라면, 연결된 애드온도 로드 시점부터 잠긴 상태로 시작해야 하기 때문이다.

3. **기존 로직과의 정합성**:
   - "전체 선택" 체크박스는 이미 `.item-check:not([disabled])`만 대상으로 하므로, 잠긴 애드온은 자동으로 전체선택 대상에서 빠진다 — 추가 수정 불필요.
   - `updateSummary()`는 이미 체크된 항목만 합산하므로 수정 불필요.
   - 수량 변경(`qty-update` 등) 로직과는 독립적이라 상호작용 없음.

## 테스트

뷰/JS 단의 국소적 UI 동작 변경으로, 이 저장소의 PHPUnit 스위트(Service/Model 중심)로는 검증되지 않는다. 브라우저에서 다음을 수동 확인한다:

- 본품+애드온이 함께 담긴 장바구니에서 본품 체크 해제 → 애드온이 자동으로 해제되고 체크박스가 잠기는지(클릭해도 반응 없음).
- 잠긴 상태에서 본품을 다시 체크 → 애드온이 잠금 해제되고, 해제 직전 선택 상태로 복원되는지(선택돼 있던 애드온은 다시 선택됨, 해제돼 있던 애드온은 계속 해제 상태).
- 본품이 품절이라 로드 시점부터 미체크인 경우, 연결된 애드온도 로드 시점부터 잠긴 채로 표시되는지.
- 본품 없는 고아 애드온은 기존처럼 완전히 독립적으로 체크/해제되는지(회귀 확인).
- "전체 선택" 토글, 개별 수량 변경, 결제 버튼 활성화가 기존처럼 정상 동작하는지(회귀 확인).
